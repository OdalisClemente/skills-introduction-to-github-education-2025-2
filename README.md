## 🌟 ¿Qué aprenderás en este curso?

Este repositorio contiene un curso completo y estructurado para aprender RStudio desde cero hasta nivel avanzado. Diseñado para estudiantes, investigadores y profesionales que quieren dominar el análisis de datos con R.

### 🎓 Objetivos de Aprendizaje

- ✅ **Fundamentos de R y RStudio**: Instalación, configuración y primeros pasos
- ✅ **Manipulación de Datos**: Importar, limpiar y transformar datos
- ✅ **Visualización de Datos**: Crear gráficos impresionantes con ggplot2
- ✅ **Análisis Estadístico**: Desde estadística descriptiva hasta modelos avanzados
- ✅ **Programación en R**: Funciones, loops y programación eficiente
- ✅ **R Markdown**: Crear reportes y documentos reproducibles
- ✅ **Proyectos Prácticos**: Casos de estudio del mundo real

## 🚀 Inicio Rápido

### Prerrequisitos
- 💻 Computadora con Windows, macOS o Linux
- 🌐 Conexión a internet
- 📝 Ganas de aprender

### Instalación

1. **Descarga R**
   ```bash
   # Visita: https://cran.r-project.org/
   # Descarga la versión apropiada para tu sistema operativo
   ```

2. **Descarga RStudio**
   ```bash
   # Visita: https://rstudio.com/products/rstudio/download/
   # Descarga RStudio Desktop (versión gratuita)
   ```

3. **Clona este repositorio**
   ```bash
   git clone https://github.com/OdalisClemente/skills-introduction-to-github-education-2025-2.git
   cd skills-introduction-to-github-education-2025-2
   ```

## 🎯 Roadmap de Aprendizaje

| Semana | Módulo | Temas | Proyecto |
|--------|--------|-------|----------|
| 1 | Introducción | Instalación, IDE, conceptos básicos | Setup completo |
| 2 | Fundamentos | Variables, tipos de datos, operadores | Calculadora básica |
| 3 | Datos | Import/export, limpieza, transformación | Análisis de ventas |
| 4 | Visualización | ggplot2, gráficos interactivos | Dashboard de datos |
| 5 | Estadísticas | Descriptiva, inferencial, correlaciones | Estudio de mercado |
| 6 | Programación | Funciones, loops, debugging | Automatización |
| 7 | R Markdown | Reportes, presentaciones, web | Reporte ejecutivo |
| 8 | Proyecto Final | Integración de conocimientos | Análisis completo |
